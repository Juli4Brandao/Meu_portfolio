# 💻 Portfólio | Júlia Andreza

Olá! 👋  
Este é o meu portfólio pessoal, desenvolvido com **React + Vite**, onde apresento minha trajetória, habilidades técnicas e evolução como desenvolvedora Full Stack.

O objetivo deste projeto é demonstrar boas práticas de desenvolvimento front-end, organização de código e componentização utilizando React.

---

## ✨ Visão Geral

- Portfólio em formato **one-page**
- Layout moderno e responsivo
- Componentização com React
- Código organizado e de fácil manutenção
- Estilização com CSS puro (dark mode)

---

## 🚀 Tecnologias Utilizadas

- **React**
- **JavaScript (ES6+)**
- **Vite**
- **HTML5**
- **CSS3**
- **Git & GitHub**
